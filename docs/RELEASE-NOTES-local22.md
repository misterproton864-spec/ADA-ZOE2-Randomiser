# ADA 6.4.15-local.22 - Experimental Beta

The first public GitHub snapshot of ADA - The ZOE2 MARS Randomiser. Original ADA code is released under MIT. This project is independent of Cronos.

Download **ADA-Beta-Tester-Edition-6.4.15-local.22-github.1.zip** from the assets below. Extract the entire ZIP and run **ADA Randomiser.exe**. The automatically generated Source code archives do not include the runtime needed by the portable app.

`github.1` adds public licensing, third-party notices and recovered helper source to the sealed Local.22 distribution. The application and helper binary bytes remain unchanged. No Local.23 fixes are included.

Requires Windows x64, .NET Framework 4.8 and your own supported Steam installation of ZOE2 MARS. Close the game for Build/Apply/Restore. After starting it, use **Attach at main menu** before loading a save or mode.

This is a tester release. Vic Viper, Inhert, Anubis and Aumaan Anubis can stall in shuffled arenas. Triple health HUD bars and clone fights remain experimental. An Ardjet victory crash in the Viola AI arena has been reported. Read `KNOWN-ISSUES.md` before a long run.

Recorded Local.22 offline checks covered 18 boss spawn phases, 6 Survival stages, 8 Boss Sequence encounters and 6 Extra Missions stages. Packaging checks verify the baseline SHA-256, unchanged application files, ZIP CRC and manifest hashes. These checks do not establish a clean gameplay run or second-PC qualification.

Report problems through this repository's Issues tab with the seed, options, mode, arena, replacement boss and Attach status. ADA's Export bug report can help; review it before posting. Do not upload game assets, saves or crash dumps publicly.

The package contains no Konami game assets. See `LICENSE` and `THIRD-PARTY-NOTICES.txt` for original and third-party terms.
