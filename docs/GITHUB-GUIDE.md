# Your ADA GitHub repository

This is a separate repository from Cronos. Sharing a GitHub account does not join the repositories, histories, collaborators or downloads.

- **Code** contains the source and documentation. The README is the project homepage.
- A **commit** records a named snapshot of changes.
- A **branch** lets you work on a change before adding it to `main`.
- **Push** uploads local commits to this repository.
- **Issues** holds bug reports and feature requests.
- A **pull request** proposes a change for review.
- **Releases** holds versioned downloads. Testers should choose the attached ADA tester ZIP, rather than the automatically generated Source code ZIP.
- A **pre-release** marks a testing build, rather than a stable release.
- **Actions** runs the repository's automated static checks. A green result does not certify gameplay.

In GitHub Desktop, check **Current repository** says **ADA-ZOE2-Randomiser** before committing or pushing ADA work. Select Cronos separately when working on Cronos. Future releases can be added under the same ADA repository without creating another repository.
